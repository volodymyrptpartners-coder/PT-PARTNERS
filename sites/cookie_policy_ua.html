Політика використання Cookie

Ця сторінка пояснює як працює система згоди користувача на основі Google Consent Mode v2 та як обробляються cookie на цьому сайті.

1. Google Consent Mode

Google Consent Mode керує тим, як працюють аналітика та реклама залежно від згоди користувача.

Режим Опис
Basic Consent Mode Всі рекламні та аналітичні cookie блокуються до отримання згоди
Advanced Consent Mode Відправляються анонімні (cookieless) сигнали навіть до згоди користувача
У цій реалізації використовується підхід: default = denied (blocking behavior).

2. Категорії cookie

Категорія Опис Статус
Necessary Базова робота сайту (без неї сайт не функціонує) Завжди активна
Preferences Збереження налаштувань користувача Опціонально
Statistics Аналітика (Google Analytics 4) Опціонально
Marketing Реклама та ремаркетинг Опціонально

Елемент Поведінка

Рекламні сервіси Вимкнені
Consent state Встановлено як denied

5. Що бачить Google

Basic Consent Mode

Поводження Результат
Cookies заблоковані Немає user-level ідентифікації
Аналітика Лише мінімальні або агреговані сигнали

Advanced Consent Mode

Поводження Результат
Cookieless pings Анонімні сигнали до згоди
Моделювання даних Google формує статистику на основі моделей
Advanced режим можливий лише при відповідній конфігурації Google Tag / GTM.

6. Google Tag Manager (GTM)

Сайт використовує Google Tag Manager — систему керування аналітикою та рекламними тегами.

Етап Опис
1 Завантажується GTM контейнер
2 Ініціалізується dataLayer
3 Встановлюється consent = denied
4 Застосовується вибір користувача 
<script>
window.dataLayer = window.dataLayer || [];
function gtag(){ dataLayer.push(arguments); }

gtag('consent','default',{
  ad_storage:'denied',
  analytics_storage:'denied',
  ad_user_data:'denied',
  ad_personalization:'denied'
});
</script>

7. Збереження налаштувань

Вибір користувача зберігається локально в браузері: 

cookie_consent_settings = {
  necessary: true,
  preferences: boolean,
  statistics: boolean,
  marketing: boolean
}

8. GDPR та ePrivacy (основні принципи)

Обробка даних на цьому сайті відповідає вимогам GDPR (Regulation (EU) 2016/679) та ePrivacy Directive.

Основні принципи GDPR

Принцип Опис
Lawfulness, fairness, transparency Дані обробляються законно, прозоро та з чіткою метою
Purpose limitation Дані використовуються тільки для визначених цілей (аналітика, реклама)
Data minimization Збираються лише необхідні дані
Storage limitation Дані не зберігаються довше ніж потрібно
Integrity & confidentiality Дані захищені від несанкціонованого доступу

ePrivacy (Cookie Law)

Правило Застосування
Необхідна згода Аналітика та маркетингові cookie активуються лише після згоди
Необхідні cookie Можуть використовуватись без згоди (робота сайту)
Прозорість Користувач має бути поінформований про всі типи cookie
