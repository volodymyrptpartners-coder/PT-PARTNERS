Политика использования Cookie

Эта страница объясняет, как работает система согласия пользователя на основе Google Consent Mode v2 и как обрабатываются куки на этом сайте.

1. Google Consent Mode

Google Consent Mode управляет тем, как работают аналитика и реклама в зависимости от согласия пользователя.

Режим Описание
Basic Consent Mode Все рекламные и аналитические cookie блокируются до получения согласия
Advanced Consent Mode Отправляются анонимные (cookieless) сигналы даже до согласия пользователя
В этой реализации используется подход: default = denied (blocking behavior).

2. Категории cookie

Категория Описание Статус
Высшее Базовая работа сайта (без нее сайт не функционирует) Всегда активна
Preferences Сохранение настроек пользователя Опционально
Statistics Аналитика (Google Analytics 4) Опционально
Marketing Реклама и ремаркетинг Опционально

3. Мапинг Google параметров

Google параметр Категория
analytics_storage Statistics
ad_storage Marketing
ad_user_data Marketing
ad_personalization Marketing

4. Что происходит до согласия

Элемент Поведение
GA4 (аналитика) Не использует cookies, данные минимальны или отсутствуют
Рекламные сервисы Выключены
Consent state Установлено как denied

5. Что видит Google

Basic Consent Mode

Обращение Результат
Cookies заблокированы Нет user-level идентификации
Аналитика Только минимальные или агрегированные сигналы

Advanced Consent Mode

Обращение Результат
Cookieless pings Анонимные сигналы к согласию
Моделирование данных Google формирует статистику на основе моделей
Advanced режим возможен только при соответствующей конфигурации Google Tag/GTM.

6. Google Tag Manager (GTM)

Сайт использует Google Tag Manager – систему управления аналитикой и рекламными тэгами.

Этап Описание
1 Загружается контейнер GTM
2 Инициализируется dataLayer
3 Устанавливается consent = denied
4 Применяется выбор пользователя 
<script>
window.dataLayer = window.dataLayer || [];
function gtag(){ dataLayer.push(arguments); }

gtag('consent','default',{ 
ad_storage:'denied', 
analytics_storage:'denied', 
ad_user_data:'denied', 
ad_personalization:'denied'
});
</script>

7. Сохранение настроек

Выбор пользователя сохраняется локально в обозревателе: 

cookie_consent_settings = { 
necessary: ​​true, 
preferences: boolean, 
статистика: boolean, 
marketing: boolean
}

8. GDPR и ePrivacy (основные принципы)

Обработка данных на этом сайте отвечает требованиям GDPR (Regulation (EU) 2016/679) и ePrivacy Directive.

Основные принципы GDPR

Принцип Описание
Lawfulness, fairness, transparency Данные обрабатываются законно, прозрачно и с четкой целью
Purpose limitation Данные используются только для определенных целей (аналитика, реклама)
Data minimization Собираются только необходимые данные
Storage limitation Данные не сохраняются дольше, чем требуется
Integrity & confidentiality Данные защищены от несанкционированного доступа

ePrivacy (Cookie Law)

Правило Применение
Необходимое согласие Аналитика и маркетинговые cookie активируются только после согласия
Необходимые cookie Могут использоваться без согласия (работа сайта)
Прозрачность Пользователь должен быть проинформирован обо всех типах cookie
